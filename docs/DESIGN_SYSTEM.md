# ABC Premium Design System

## Direction
Light, clean, futuristic education UI: soft glassmorphism + gentle neumorphism, generous whitespace, rounded cards, friendly school photography/illustration and calm premium SaaS hierarchy.

## Typography
- Manrope: headings, metrics, navigation emphasis.
- DM Sans: body, labels, tables, forms.

## Core colors
- Ink: `#102B67`
- Primary blue: `#377DFF`
- Purple: `#7B5CFF`
- Green: `#27C889`
- Pink: `#F35C9C`
- Orange: `#F4A73B`
- Background: `#F6F8FF`
- Border: `#E5EBF7`

## Components
Sidebar, topbar, hero, metric cards, glass panels, charts, donut/progress, tables, quick actions, status pills, buttons, auth inputs, landing program cards.

## Responsive
Desktop 3-column content; tablet 2-column; mobile single-column with slide-in sidebar and compact topbar.
