# Agent 00 — Manager
Role: orchestrate the complete UI build/audit cycle.
Responsibilities:
- Maintain task ownership and acceptance criteria.
- Route design gaps from audit agents back to the correct design agent.
- Require all routes, assets, responsive states and shared components to pass before release.
- Never accept a dashboard merely because it renders; compare structure against its reference.
Cycle: PLAN → DESIGN → IMPLEMENT → AUDIT → GAP REPORT → FIX → RE-AUDIT → RELEASE.
